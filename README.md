# TPI-digital-twin-farm
Aplicatie IoT care optimizează costurile unei ferme
Ne-am propus sa facem copie digitala a fermei care foloseste datele preluate de la actuala ferma 
si face simulari in conditi neobisnuite  sau diferite pentru a vedea daca recolta are de suferit sau de castigat. 
Dorim si o estimare caculand costurile de a oferi conditile cele mai bune in detrimentul productiei de exemplu daca costurile de irigare la o productie depasesc castigul adus de pe urma aceseia insemana ca nu meerita irigarea. In schimb daca costurile sunt acoperite si depasite de profit recomanda si poate actiona sa porneasca sistemele de irigare.
